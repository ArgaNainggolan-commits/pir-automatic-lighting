# Lampu Otomatis Berbasis Sensor Gerak (PIR Sensor)

Proyek sistem kendali kelistrikan cerdas yang memanfaatkan sensor inframerah pasif (*Passive Infrared*) untuk mendeteksi kehadiran manusia dan mengotomatisasi sistem pencahayaan ruangan secara efisien.

## 🚀 Fitur Utama
* **Motion-Triggered Activation:** Lampu menyala secara otomatis seketika saat sensor mendeteksi pergerakan di dalam zona jangkauan.
* **Energy Efficiency:** Mencegah pemborosan energi listrik dengan mematikan lampu secara otomatis setelah area ditinggalkan atau tidak ada aktivitas.

## 🛠️ Stack Teknologi
* **Hardware:** PIR Motion Sensor (HC-SR501), Relay Module, Rangkaian Catu Daya & Lampu AC/DC.
* **Bahasa Pemrograman:** C / C++.
